# Kraken 2.0 brand

Concept **Reach & Return**: a K on an 8×8 grid with one stroke weight. The upper arm reaches out;
the lower arm comes back and coils, tentacle-like, around a document. The colour flows blue → red
along the tentacle and ends on the red of the document.

All files are generated by `build_logo.py` (exact geometry, no font dependency). Edit the
`Geometry`, `Type` or palette constants there and run `python brand/build_logo.py`.
`preview.html` shows every file on light and dark at several sizes.

| File | Use |
|---|---|
| `kraken-lockup.svg` / `-dark` / `-mono` | Mark + wordmark: title slides, page headers |
| `kraken-mark.svg` / `-dark` / `-mono` | Mark alone (transparent background) |
| `kraken-wordmark.svg` / `-dark` | Wordmark alone |
| `kraken-app-icon.svg`, `favicon.svg` | Navy rounded tile: favicon, avatar, app icon |

`-mono` files use `currentColor` (inline them in HTML to colour them with CSS).

Palette: navy `#0A1A3F`, electric blue `#2F6BFF`, crimson `#E5283A`, paper `#F5F6F8`.
The tentacle ramp is interpolated in OKLCH (blue → violet → magenta → red).

Rules: keep a clear space of at least one stroke (1/8 of the mark height) around the mark;
below 24 px use the app icon rather than the bare mark.
